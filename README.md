## 1. Дерево процессов по данным /proc

Файл: `ptree.py`

Программа читает информацию о процессах непосредственно из `/proc` и не использует команду `ps`.

Для каждого процесса выводятся:

- PID
- состояние процесса
- RSS
- вложенность процесса в дереве

Запуск:

```bash
python3 ptree.py
